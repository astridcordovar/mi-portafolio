## Reportar un error
Si encuentras un fallo, abre un **Issue** en el repositorio incluyendo:
1. **Pasos** para reproducir el error.
2. **Resultado esperado** vs. **Resultado actual**.
3. **Captura de pantalla** o mensaje de error.

## Proponer una mejora

Abre un **Issue** o un **Pull Request** explicando:
1. **Qué** quieres mejorar y **por qué** es necesario.
2. **Cómo** sugieres implementarlo (tu propuesta técnica)

## Checklist de revision 
Antes de enviar tu código (Pull Request), asegúrate de cumplir con:
- [ ] El código compila/funciona sin errores locales.
- [ ] Se añadieron pruebas unitarias (si aplica).
- [ ] La documentación y el README fueron actualizados.
