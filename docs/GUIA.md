# Tienda TECSUP

El carrito de la tienda muestra el producto, precio, cantidad y el monto total.

## Carrito

El carrito debe listar el nombre del producto, su precio y cantidad.

### Total

El monto total debe mostrar el sumatoria de todos los productos del carrito.

## Estilos
- El titulo debe mostrarse en color azul.
- El carrito debe es una tabla.
- La tabla del carrito debe mostrarse con bordes.

## Pasos de instalacion
1. Crea el archivo README
2. El archivo debe tener la extension .md
3. Hacer git add, commit y push
